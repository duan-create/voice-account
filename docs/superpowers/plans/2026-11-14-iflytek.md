# iFlytek Optional ASR Implementation Plan

> Execute inline with the executing-plans and test-driven-development skills.

**Goal:** Android cloud-first dictation with same-audio offline fallback.
**Architecture:** Separate credential vault, WebSocket client and settings module;
extend the existing native adapter rather than replace the voice state machine.
**Tech Stack:** Capacitor 8, Android Keystore, Web Crypto, IndexedDB, WebSocket.
**Spec:** `docs/superpowers/specs/2026-11-14-iflytek-design.md`

## Constraints
- Android only; PWA recognition unchanged.
- No changes to bill schema, parser, CRUD or Whisper model.
- Cloud disabled by default; credentials excluded from ledger and backup.
- Same 30-second RAM-only audio; cancellation never triggers fallback.
- Explicitly distinguish automated simulations from real service/device tests.
